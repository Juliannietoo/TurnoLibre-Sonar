# TurnoLibre

Aplicación web para el intercambio de turnos entre trabajadores de una organización ficticia con turnos rotativos (Hospital Comarcal Vega Alta, ficticio). Proyecto de la asignatura Gestión de Proyectos Software.

## Estructura

| Ruta | Contenido |
|---|---|
| `.specify/memory/constitution.md` | Principios no negociables del proyecto |
| `specs/product/mission.md` | Razón de ser del producto |
| `specs/product/goals.md` | Objetivos, métricas, alcance, exclusiones, supuestos y restricciones |
| `specs/product/business-rules.md` | Reglas de negocio de los intercambios de turno |
| [`specs/product/catalogo.md`](specs/product/catalogo.md) | Catálogo H2: épicas, historias, prioridad MoSCoW, estimaciones individuales y consensuadas, ajuste de alcance (D-18), dependencias y plan por iteración |
| [`specs/product/non-functional-requirements.md`](specs/product/non-functional-requirements.md) | Requisitos no funcionales NFR-001 a NFR-009 |
| `specs/EP-001-…/spec.md` … `specs/EP-007-…/spec.md` | Una ficha por épica con sus historias, criterios de aceptación y verificación |
| `docs/organization/company.md` | Ficha de la empresa y del equipo |
| `docs/organization/team-charter.md` | Acuerdos de trabajo del equipo |
| `docs/organization/capacity.md` | Capacidad nominal y efectiva por persona y sprint |
| `docs/quality/definition-of-ready.md` | Definition of Ready |
| `docs/quality/definition-of-done.md` | Definition of Done |
| `docs/risks/technical-risks.md` | Riesgos técnicos con probabilidad, impacto y mitigación |
| `docs/planning/` | Excel de planificación |
| `.github/agents/` | Instrucciones de referencia de los agentes del H3 (Requirements Agent y Planning Agent), adaptadas de las plantillas del profesorado |
| `.claude/agents/` | Los mismos agentes preparados para Claude Code |
| [`docs/agents/README.md`](docs/agents/README.md) | Cómo ejecutar los agentes con Claude Code, ChatGPT y Antigravity |
| `docs/reviews/` | Informes versionados que generan los agentes |
